# Pasta `data`

Esta pasta contém a base de conhecimento fictícia utilizada pelo Sentinel.

## Arquivos

- `sinais_atencao.json`: sinais de atenção e orientações de análise.
- `procedimentos.csv`: próximos passos relacionados aos sinais.
- `exemplos_casos.json`: casos fictícios para testes.
- `glossario.md`: definições dos principais conceitos.

## Aviso

Os dados foram criados exclusivamente para fins acadêmicos. Eles não representam regras completas de uma seguradora e não devem ser utilizados para decisões reais sobre clientes ou sinistros.
